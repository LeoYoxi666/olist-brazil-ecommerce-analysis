# Olist Power BI 中文仪表盘搭建指南

本指南将 Python 分析结果搭建成 8 页全中文 Power BI 运营看板。页面结构参考淘宝用户分析项目：使用经过验证的聚合数据、统一主题、固定指标口径和可复现刷新流程，不在 Power BI 内重复清洗原始大表。

## 1. 中文模型与导入设置

### 1.1 刷新中文聚合数据

在项目根目录运行：

```powershell
.\powerbi\refresh_exports.ps1
```

脚本会生成 11 张带 UTF-8 BOM 的 CSV。所有表头、品类、RFM 客群、配送状态、建议行动和布尔标签均为简体中文，州代码、日期和业务 ID 保持原值。

### 1.2 导入并重命名表

在 Power BI Desktop 中依次选择 **主页 → 获取数据 → 文本/CSV**，导入 `powerbi/data/` 中除 `README.md` 外的 11 张 CSV，并选择 Import 模式。导入后按下表修改查询名称：

| CSV 文件 | Power BI 中文表名 |
|---|---|
| `executive_summary.csv` | 经营决策摘要 |
| `monthly_metrics.csv` | 月度经营指标 |
| `rfm_segments.csv` | 用户RFM分群 |
| `cohort_retention.csv` | 月度同期群留存 |
| `cohort_rfm_targets.csv` | 同期群RFM目标 |
| `category_metrics.csv` | 品类经营指标 |
| `state_metrics.csv` | 州级经营指标 |
| `seller_metrics.csv` | 卖家经营指标 |
| `seller_state_delivery_actions.csv` | 卖家州配送行动 |
| `delivery_review.csv` | 配送评价关联 |
| `logistics_summary.csv` | 物流指标摘要 |

文件名为了兼容 Python 和 Git 保留英文；Power BI 字段窗格、页面和视觉对象必须只显示上表中的中文表名。

### 1.3 设置字段类型

- `订单月份`、`首购同期群月份`：日期。
- 含 `GMV`、`价格`、`价值` 的字段：定点小数，格式 `R$`，保留两位小数。
- 含 `率`、`占比`、`比例` 的字段：小数，百分比格式，保留两位小数。
- 订单、买家、客户、排名、层级、月序和门槛：整数。
- `是否延迟`、`是否符合目标条件`、`是否符合评估条件`、`是否符合风险排名条件`：文本。
- 州代码和业务 ID：文本，不求和。

### 1.4 关闭自动关系

11 张表分别代表月度、品类、州、卖家、RFM 和同期群等不同聚合粒度。进入模型视图，删除自动建立的关系，并关闭当前文件的自动关系检测，避免多对多关系导致重复计算。每一页只使用对应粒度的数据表。

### 1.5 导入主题与中文度量值

通过 **视图 → 主题 → 浏览主题** 导入 `powerbi/olist_theme.json`。再按照 `powerbi/measures.dax` 创建度量值。DAX 已使用中文表名和字段名，创建前必须完成 1.2 的查询重命名。

## 2. 页面一：经营总览

### 2.1 页面目标

让业务负责人在一页内看到经营规模、用户价值、配送风险和三项优先行动。

### 2.2 视觉对象

| 位置 | 视觉对象 | 中文字段或度量值 | 中文标题 |
|---|---|---|---|
| 顶部 | 6 个卡片 | 已完成订单、商品 GMV、活跃买家、平均订单价值、复购买家率、延迟交付率 | 与指标同名 |
| 中部左侧 | 折线图 | 订单月份、商品 GMV | 月度商品 GMV 趋势 |
| 中部右侧 | 折线图 | 订单月份、已完成订单 | 月度已完成订单趋势 |
| 底部 | 表格 | 优先级排名、优先事项、核心信号、影响对象数、相关商品GMV、建议行动 | 经营优先行动 |

页面切片器只保留 `订单月份`。页面名称设为 `01｜经营总览`。

## 3. 页面二：月度经营趋势

### 3.1 视觉对象

- 折线和簇状柱形组合图：X 轴 `订单月份`，柱为 `已完成订单`，线为 `商品GMV`；标题为“订单与商品 GMV 月度趋势”。
- 折线图：X 轴 `订单月份`，值为 `活跃买家`；标题为“月度活跃买家趋势”。
- 折线图：X 轴 `订单月份`，值为 `平均订单价值`；标题为“月度平均订单价值趋势”。
- 日期切片器：`订单月份`，默认完整趋势窗口截至 2018 年 8 月。
- 明细表：订单月份、已完成订单、商品GMV、活跃买家和平均订单价值；标题为“月度经营明细”。

页面名称设为 `02｜月度经营趋势`。

### 3.2 解读限制

2018 年 9 月为不完整月份，已在 Python 分析层排除。趋势峰值可支持季节性资源规划，但不能证明营销活动造成增长。

## 4. 页面三：用户价值与留存

### 4.1 RFM 客群

- 横向条形图：Y 轴 `RFM客群`，X 轴 `买家数`；标题为“RFM 客群规模”。
- 组合图：各客群的 `商品GMV` 与 `平均距最近购买天数`；标题为“RFM 客群价值与活跃度”。
- 卡片：`活跃买家`、`复购买家`、`复购买家率`。
- 切片器：`RFM客群`，显示冠军客户、忠诚客户、高价值客户、流失风险客户、新近活跃客户和一般客户。

### 4.2 同期群留存

- 矩阵：行 `首购同期群月份`，列 `留存月序`，值 `加权同期群留存率`；标题为“月度同期群留存矩阵”。
- 对留存率应用由浅蓝到深蓝的背景色条件格式。
- 折线图：X 轴 `留存月序`，图例 `首购同期群月份`，值 `加权同期群留存率`；标题为“同期群留存曲线”。

页面名称设为 `03｜用户价值与留存`。留存率是精确月留存，不是累计生存率；近期同期群的未来月份必须保持空值。

## 5. 页面四：留存目标与客户行动

### 5.1 留存行动客群

- 表格：优先级排名、首购同期群月份、RFM客群、优先级层级、目标客户数、目标客户商品GMV和建议客户旅程；标题为“留存目标客群”。
- 页面筛选：`是否符合目标条件` 等于“是”。
- 卡片：`合格目标客户`、`合格目标客户 GMV`。

页面名称设为 `04｜留存目标与客户行动`。建议旅程是待验证的运营假设，不是预测增量；正式执行应保留对照组。

## 6. 页面五：品类销售与体验

### 6.1 视觉对象

- 横向条形图：Top 10 `品类名称`，按 `商品GMV` 降序；标题为“商品 GMV 前十品类”。
- 散点图：X 轴 `平均评价得分`，Y 轴 `商品GMV`，气泡大小 `已完成订单`，详细信息 `品类名称`；标题为“品类价值与评价表现”。
- 横向条形图：Top 10 品类的 `平均运费占比`；标题为“重点品类运费占比”。
- 表格：品类名称、已完成订单、商品GMV、平均商品价格、平均运费占比和平均评价得分；标题为“品类经营明细”。

页面名称设为 `05｜品类销售与体验`。高 GMV 且评价低于平台均值的品类应优先检查质量与物流，不能直接解释为推广机会。

## 7. 页面六：区域配送与评价

### 7.1 州级地图与排名

- 填充地图：位置 `客户州`，颜色饱和度 `延迟交付率`，工具提示包含已完成订单、商品GMV、平均送达天数和平均评价得分；标题为“各州延迟交付率”。
- 风险条形图：按 `延迟订单` 降序；页面筛选 `是否符合风险排名条件` 等于“是”；标题为“州级配送风险排名”。
- 切片器：`客户州`；标题为“客户所在州”。

将 `客户州` 的数据类别设为“州或省”，并在页面注释中标明国家为巴西，避免 Power BI 将两位州代码解析到其他国家。州代码 `SP`、`RJ`、`MG` 等是业务数据，不翻译。

### 7.2 延迟与评价关系

- 簇状柱形图：轴 `配送状态`，值 `平均评价得分`；标题为“准时与延迟订单评价对比”。
- 卡片：`延迟订单`、`延迟交付率`、`平均评价得分`。
- 表格：配送状态、订单数、平均评价得分和低分评价率；标题为“配送评价明细”。

页面名称设为 `06｜区域配送与评价`。该页展示诊断性关联，不能将低评分全部归因于配送延迟。

## 8. 页面七：卖家配送风险

### 8.1 卖家风险

- 散点图：X 轴 `延迟交付率`，Y 轴 `商品GMV`，气泡大小 `已完成订单`，详细信息 `卖家ID`；标题为“卖家规模与配送风险”。
- 切片器：`卖家州`；标题为“卖家所在州”。
- 页面筛选：`是否符合风险排名条件` 等于“是”。
- 卡片：`合格风险卖家`。

页面名称设为 `07｜卖家配送风险`。优先关注延迟率较高且业务影响范围较大的卖家，避免被小样本极端值误导。

## 9. 页面八：卖家—州配送行动队列

### 9.1 卖家—州行动队列

- 表格：优先级排名、卖家ID、卖家州、客户州、已完成订单、延迟订单、延迟订单商品GMV、延迟交付率和建议行动；标题为“卖家—州配送行动队列”。
- 按 `优先级排名` 升序；对延迟交付率和延迟订单商品GMV使用条件格式。
- 切片器：`建议行动`，显示“复核卖家发货SLA”或“复核承运线路容量与路由”。
- 卡片：`行动线路数`。

页面名称设为 `08｜卖家—州配送行动队列`。行动标签只表示排查起点，不能直接用于责任认定。

## 10. 统一中文页面格式

1. 画布使用 16:9，背景色 `#F4F6FA`，卡片使用白色圆角背景。
2. 主色使用 `#2F6FED`，正常状态使用 `#14B8A6`，风险强调使用 `#D86A52`。
3. 页面标题统一为“序号｜中文业务主题”，左上对齐。
4. 所有视觉对象必须手工设置中文标题，不使用 Power BI 自动生成的“字段名求和”等标题。
5. 金额显示 `R$` 并保留两位小数；百分比保留两位；数量使用千位分隔符。
6. 每页右上角放置“数据截至 2018-08”和“已交付订单口径”。
7. 表格默认按业务优先级排序，不以字母顺序代替风险排序。
8. 字段窗格不得出现面向展示者的英文别名；技术文件名、业务 ID 和巴西州代码除外。

- 11 个查询采用 1.2 中规定的中文表名，字段窗格中不出现 snake_case 字段。
- 品类名称、RFM 客群、配送状态、建议客户旅程和建议行动均显示中文。
- 总订单为 96,478，商品 GMV 约为 R$13.22M，活跃买家为 93,358。
- 复购买家率为 3.00%，延迟交付率为 8.11%，平均评价得分约为 4.16。
- 月度趋势最后一个完整月份为 2018-08，同期群未来不可观察月份保持为空。
- 州代码保持 `SP`、`RJ`、`MG` 等原始缩写，不被翻译。
- 点击“刷新”后 11 张表均成功加载，页面无视觉对象错误或乱码。
